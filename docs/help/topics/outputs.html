    List of outputs¶

    This section provides a summary of the output files generated by EddyFlow. Some of the files described below may not be included in your output folder, depending upon the files specified in the Output Files tab (see Output files). A full set of output files is shown in Figure 3‑2.

    Figure 3‑2. Output folder created by EddyFlow when all outputs are selected.

    Table 3‑1 provides more details about the folders and files created by EddyFlow.

    File/Folder Name Description
    eddyflow_binned_cospectra Folder containing binned cospectra files (see Binned cospectra outputs).
    eddyflow_binned_ogives Folder containing binned ogives files (see Binned ogives).
    eddyflow_full_cospectra Folder containing full cospectra files (see Full cospectra).
    eddyflow_spectral_analysis Folder containing spectral analysis files (see Spectral analysis).
    eddyflow_stats Folder containing statistical output files (see Stats).
    eddyflow_user_stats Folder containing user statistics files.
    eddyflow_OutputID_essentials_yyyy-mm-ddThhmmss.csv Intermediate flux results that have not been corrected. EddyFlow uses this file when you want to quickly reprocess data. See Using results from previous runs for more information.
    eddyflow_OutputID_biomet_yyyy-mm-ddThhmmss.csv Summarized output variables.
    eddyflow_OutputID_fluxnet_yyyy-mm-ddThhmmss.txt File conforming FLUXNET and AmeriFlux FP-In Standards for labels, units and format. Features new output variables, including many intermediate results, statistics on all high-frequency variables, covariances between all high-frequency variables, biomet mean values and metadata, as well as results of new implementations See The full output file for the columns added in recent versions (per-gas SPEC_CORR_LI7700_<A|B|C>_<GAS>, <GAS>_DETLIM, always-written *_KID, optional test_rf families).
    eddyflow_OutputID_full_output_yyyy-mm-ddThhmmss.csv Final flux results. New columns: corr_iter_dev (iterative correction) and <gas>_detlim (detection limit); T* sign corrected in files written by eddyflow_fcc. See The full output file.
    eddyflow_OutputID_metadata_yyyy-mm-ddThhmmss.csv A summary of information stored in each of the metadata files for the project.
    eddyflow_OutputID_qc_details_yyyy-mm-ddThhmmss.csv A summary of errors and tests for each 30 minute data set.
    eddyflow_OutputID_flux_despiking_yyyy-mm-ddThhmmss.csv Written only when Post-flux despiking (STL) (test_pfd) is on: NEE, H and LE of the whole run with a spike flag and a cleaned value each. See The full output file and Statistical tests.
    eddyflow_OutputID_storage_cleaning_yyyy-mm-ddThhmmss.csv Written only when Storage-flux cleaning (test_stor_clean) is on: the storage term of each gas with a spike flag and a cleaned value. See Statistical tests.
    processing_yyyy-mm-ddThhmmss.eddyflow EddyFlow project file (legacy .eddypro project files can still be imported and are auto-converted).

    Binned cospectra outputs¶

    This folder includes one .csv file for each 30 minute dataset. See Calculating spectra, cospectra, and ogives for more information.

    Binned ogives¶

    This folder includes one .csv file for each 30 minute dataset. See Calculating spectra, cospectra, and ogives for more information.

    Full cospectra¶

    This folder includes one .csv file for each 30 minute dataset. See Calculating spectra, cospectra, and ogives for more information.

    Spectral analysis¶

    This folder includes spectra and cospectra data files in .csv format. It also includes a spectral assessment file that can be used to reprocess a data set if the spectral assessment file applies. See Calculating Spectral correction factors for more information.

    Stats¶

    The stats folder includes a .csv file for each level of processing.

    User stats¶

    The user stats folder includes a .csv file for each level of processing.

    What changed in recent versions¶

    • New file eddyflow_OutputID_flux_despiking_yyyy-mm-ddThhmmss.csv (with test_pfd), and eddyflow_OutputID_storage_cleaning_yyyy-mm-ddThhmmss.csv (with test_stor_clean); both sit in the main output folder, not in eddyflow_stats.
    • New columns in the full output: corr_iter_dev, <gas>_detlim. In the FLUXNET file: SPEC_CORR_LI7700_<A|B|C>_<GAS> (replacing three fixed columns), <GAS>_DETLIM, and with test_rf the families _AL1, _DDI, _HF5, _HF10, _HD5, _HD10, _DIP, _CCF at the end of the row. The per-variable *_KID columns are always written.
    • Changed values: LI-7700 methane flux (multipliers B and C now applied, larger magnitude; Burba heating applied per gas); T* and TSTAR written by eddyflow_fcc flip sign (they were wrong); *_KID computed on the flat-line-corrected series.
    • Renamed in the log summary: S4_instrument_filled is now S4_borrowed.

    The column-by-column description is in The full output file.
